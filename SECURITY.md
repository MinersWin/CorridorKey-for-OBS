# Security

Only the latest development branch and latest release receive fixes. This project
is pre-alpha; inference and model downloads are not implemented yet.

Report a suspected vulnerability through GitHub's private vulnerability reporting,
if enabled, or email admin@moritz-mantel.de. Include the affected version, steps to
reproduce it, the impact and relevant logs. Remove personal data from the logs.
Keep credentials and unpatched exploit details out of public issues.
