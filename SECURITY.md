# Security

Only the latest development branch and latest release receive fixes. This project
is pre-alpha; inference and model downloads are not implemented yet.

Report suspected vulnerabilities privately through GitHub's private vulnerability
reporting, if enabled, or email admin@moritz-mantel.de. Include the affected version,
reproduction steps, impact and relevant logs with personal data removed. Do not
publish credentials or unpatched exploit details in public issues.
