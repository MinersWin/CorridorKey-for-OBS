# Model-manager captures

Captured on 29 October 2026 in OBS 33.0.0 with Qt 6.11.1, using a plugin built
against the OBS 30.2 SDK. These PNGs contain the real Qt dialog client areas.
The mouse cursor is excluded. The main sets use 200% scaling; metadata files
record the measured dimensions and device-pixel ratios.

State previews use a tiny local fixture and identify themselves in the window.
`import-ready` shows a real accepted folder import through W04 and the test
binder. The bundled licence previews display the exact W04 records. These
captures contain no model inference or GPU performance measurements.
