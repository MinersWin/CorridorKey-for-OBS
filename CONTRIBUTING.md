# Contributing

Open an issue before a substantial change. Use English for code and documentation.
Keep pull requests focused and include the build or runtime checks you ran.
Format C/C++ with clang-format 19 and CMake with gersemi 0.22.2.

Contributions must be compatible with GPL-3.0-or-later. Include the SPDX header
and state whether you grant the additional permission in LICENSE-EXCEPTION.md
for your contribution. Preserve third-party attribution. Do not copy CorridorKey
upstream implementation code or code without a compatible licence. Never commit
model weights, model graphs, credentials, generated engines or videos.

Keep model download and licence acceptance separate from the plugin's licence.
New dependencies and model manifests need a licence review and third-party notices.
Test on the affected platform and describe untested hardware or execution providers.
